## 数据真实性声明

本报告出现的所有数字（SWE-bench 分数、价格、stars 数）均来自上述来源。其中：

1. **官方数字**：SWE-bench 官方榜、各工具官网价格、GitHub 官方 stars
2. **第三方报告数字**：标注了来源，可能存在评测口径差异
3. **未经官方确认的模型版本**（如 Fable 5、Opus 4.8、Mythos Preview）：**不在核心结论中**，仅作为附录信息出现

读者若要将本报告用于商业决策，建议：
- 以 **SWE-bench 官方榜** 为模型能力的最终判据
- 以 **各工具官网** 为价格和功能的最终判据
- 以 **MCP 官方文档** 为协议支持深度的最终判据
